## Бейджи

В начале статей, если они того требуют, будут располагаться метки. Вот пример:

<span className="badge badge--info">version: 1.0.0</span> — Актуальная версия Nova SDK для данной статьи. Если указана версия ниже вашей, ничего страшного: мы стараемся поддерживать обратную совместимость SDK.

<span className="badge badge--success">Worked!</span> — Чаще всего будет встречаться около блоков кода. Означает, что данный код работает и его можно смело копировать.

<span className="badge badge--warning">Pseudocode</span> — Также будет встречаться около кода. Означает, что код не работает и/или является псевдокодом.

Бейджи группируются по цветам:

<span className="badge badge--info">info</span> — Информационный бейдж. В основном используется для показа версии SDK и/или канала SDK.

<span className="badge badge--success">success</span> — Бейдж, который показывает, что всё в порядке.

<span className="badge badge--warning">warn</span> — Бейдж для предупреждений.

Актуальная документация постоянно обновляется, поэтому этот список может неоднократно редактироваться.

## Каналы выпуска SDK

Не будем вдаваться в подробности, но упомянуть всё же стоит.

Nova SDK поставляется по трём основным каналам:

- `Stable` — выходит заметно реже других. Самые надёжные версии. Рекомендуем устанавливать именно её, если нет причин выбирать другие каналы.

- `Beta` — содержит новые функции. Не такая надёжная, как Stable, но, если есть желание использовать новые возможности, её можно попробовать.

- `Nightly` — ежедневная сборка. Каждый день собираются новые версии. Самые свежие функции, но и наименее надёжные сборки. Не рекомендуем использовать этот SDK для проектов, где важны стабильность и безопасность.
